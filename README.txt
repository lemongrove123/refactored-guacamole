AMZA MART WEBSITE

Files:
- index.html = website
- style.css = design
- script.js = products, tabs and cart

HOW TO RUN:
1. Open the folder in PyCharm.
2. Right-click index.html.
3. Open it in your browser.

No packages, server or internet connection are required.

Features:
- Light-blue modern design
- Home page
- Our Finest Stuff
- Clothing
- Accessories
- Deals
- Product cards
- Working cart
- Demo checkout
- Responsive mobile layout

No AI assistant is included.
